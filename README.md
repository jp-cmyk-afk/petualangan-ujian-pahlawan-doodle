Petualangan Legenda Pahlawan

jadilah pahlawan di dunia ini, kamu tiba-tiba terbangun di suatu tempat karena rasa ingin tahumu akan isi peti tak tertahankan. 
bangkitlah kalahkan semua monster dan hindari monster kuat untuk bertahan hidup, lewati semua map dan kembalilah ke tempatmu berasal.
